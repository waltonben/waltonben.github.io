Import format & sample

CSV or XLSX: use three columns in this order: Variant Name, Variant Code, Quantity. Name and quantity are required; leave code blank if unused. For XLSX, the first visible worksheet is imported. A header row is optional. Existing two-column name/quantity files are also accepted. Keep variant codes as text to preserve leading zeros. Import replaces the current list. Files are read in your browser.

For CSV, save as CSV UTF-8 (comma delimited). Names containing commas must be quoted, for example: "Item A, blue",AQL10020,10000. Use quantities without thousands separators, or quote them: "10,000". Blank rows are ignored. Maximum 5 MB and 500 variants.
