Install in Chrome

  1. Download and unzip RipKit-Chrome.zip.
  2. Enter chrome://extensions in Chrome’s address bar and switch on Developer mode.
  3. Click Load unpacked and select the extracted folder containing manifest.json.
  4. Open a website and click the RipKit icon in Chrome’s toolbar.
