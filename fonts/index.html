A browser-only scanner has limits. Many websites block cross-origin requests (CORS). If a scan is blocked, import a Network HAR below. Scans inspect the selected page and its linked CSS, not every page on a domain; JavaScript-only fonts may need a HAR capture.
Import a capture or paste source
  1. Open your chosen website and its browser Developer Tools.
  2. Open Network, enable Disable cache, then reload the page. Visit or scroll through the content you want to inspect.
  3. Export the network log as HAR with content and import it here.

HAR files are processed locally and never uploaded. They can contain private browsing data. Embedded font responses allow previews and downloads even when the original host blocks access.

For HTML/CSS imports, enter the original page or stylesheet URL above so relative file paths resolve correctly. Import replaces the current results.

Only data is read: imported scripts are never run. A font file on its own can also be imported to preview and download it.
